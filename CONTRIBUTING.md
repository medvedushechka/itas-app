# Разработка

## Перед началом

1. Создайте отдельную ветку.
2. Выполните `setup.ps1`.
3. Убедитесь, что тесты проходят локально.

## Требования к изменениям

- не добавлять `.env`, базы данных, логи и рабочие загрузки;
- изменения схемы оформлять новой миграцией;
- не редактировать уже опубликованные миграции;
- не ослаблять проверку файлов и очистку HTML;
- сохранять русские комментарии только там, где они действительно поясняют решение;
- не добавлять секреты и реальные учётные данные в тесты;
- для нетривиальной логики добавлять тесты.

## Проверка

```powershell
.\test.ps1
.\.venv\Scripts\python.exe scripts\check_media_integrity.py
```

## Коммиты

Используйте короткие сообщения, описывающие результат изменения, например:

```text
Добавить валидацию ссылок участников
Исправить очистку старых медиафайлов
Обновить инструкцию развёртывания
```
