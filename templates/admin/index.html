Тикер: новости
Несколько строк, порядок показа, можно отключать отдельные

Правила заполнения

  • position: порядок (меньше = раньше).
  • bullets: каждый пункт — с новой строки.
  • media_file / logo: загружай файл с компьютера → сохранится в /static/uploads/.
  • size у новостей: small или big.
  • media_type: image / gif / video.
  • Тикер: включается в /admin/ticker-settings/, новости — в /admin/ticker/.
